### Techno 
Appli statique en HTML
une API pour le site est décrite ici https://docs.sqorz.com/reference/APIs-for-Information-and-Results/

### on doit faire
entrer le nom du pilote et obtenir un affichage clair de tout son historique
classer les resultats par organisation
